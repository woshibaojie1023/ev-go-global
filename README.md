# 新能源车出海市场决策助手

> 面向中国车企出海的「目标市场决策」交互工具 —— 2027 届秋招作品集 MVP。

**在线体验**：<https://USERNAME.github.io/REPO/>

## 这是什么

一个纯静态、零依赖的单页 Web 工具：在点阵世界地图上，对全球重点新能源市场按「市场吸引力 × 进入难度」打分排名，帮助车企战略/出海部门快速判断「先打哪个市场」。

- **左侧**：重点市场综合排名榜单，支持按经济组织（RCEP / 欧盟 / CPTPP 等）筛选
- **中间**：点阵世界地图「情报指挥台」，气泡大小/颜色编码市场得分，点选国家查看详情
- **右侧**：国家简报（关税壁垒、新能源渗透、销量增速、政策、评分依据）
- 支持中 / 繁 / 英 / 日 / 韩 五语言切换，报告可导出打印为 PDF

## 技术实现

- 纯 `HTML + CSS + 原生 JavaScript`，**无框架、无网络请求、无后端**，双击 `index.html` 即可离线运行
- Canvas 2D 手绘点阵世界地图（陆地掩码 + 墨卡托投影），命中测试适配触屏热区
- 一套响应式断点体系覆盖手机 / 折叠屏 / 平板 / 笔记本 / 大屏 / 缩放桌面，含横屏矮屏与刘海安全区适配

## 目录结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | DOM 骨架 |
| `style.css` | 全部样式与响应式断点 |
| `app.js` | 渲染、地图绘制、交互逻辑 |
| `data.js` | 国家级数据集与评分模型 |
| `landmask.js` | 点阵陆地掩码 |
| `i18n.js` | 五语言文案 |

> 数据为公开资料整理的静态快照，仅供产品演示与方法论展示，不构成投资或商业决策依据。
